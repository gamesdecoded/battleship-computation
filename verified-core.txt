WORDING CORRECTIONS — SEPARATE NOTE, NOT A SILENT EDIT
The definition sheet (definition-sheet.txt) is NOT edited
by this file. Two wording issues in the sheet are corrected
here, and must be corrected in the sheet itself before a
final publishable methods note is issued:
1. Sunk detection (sheet section 6): the sheet phrases
   sunk length as "inferred from the size of the
   contiguous hit group". Code in engine.py, advanced2.py,
   and this verification run uses true-ship sunk
   announcement: a ship is sunk when all its cells are
   shot, and the defender names the sunk ship. These
   coincide when a hit group is a single ship. When two
   ships touch and their hit cells merge, group-size
   inference is ambiguous (group size is not sunk ship
   length), so true-ship detection is used. A script
   must use sunk-announcement wording, never claim
   group-size inference literally.
2. Placement "better" (sheet section 10): the sheet says
   "lower = better placement" for average shots to sink.
   That line is INVERTED for a hiding strategy and is
   NOT followed here or in numbers-log.txt. For hiding,
   higher shots = better hiding (the fleet survives
   longer), lower shots = worse hiding. Evidence in
   this run: interior 37.34 vs line-bonus, edge 50.90
   vs line-bonus — centre hiding is searched first, so
   it is worse, not better.
